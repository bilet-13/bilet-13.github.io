Fault-Tolerant Distributed Key-Value Store

Strongly consistent replicated store built on Multi-Paxos. Keeps serving as long as a majority of nodes are up; a stable-leader optimisation cuts each write from two network round trips to one. Passes 27/27 fault-injection tests covering 20% message loss, network partitions and reordering, plus a 1M+ state model check.
